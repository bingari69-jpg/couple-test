가장 중요한 순서

모든 변경은 이 순서로 해요

  1. 1
    바꾸기

    게임, 메뉴, 디자인 또는 광고에서 원하는 내용을 바꿔요.

  2. 2
    임시 저장 → 미리보기

    임시 저장은 실제 홈페이지를 바꾸지 않아요. 미리보기에서 먼저 확인하세요.

  3. 3
    게시하기

    확인이 끝나면 게시하기를 눌러 실제 이용자에게 보여줘요.

💡 임시 저장은 나만 보는 보관, 게시하기는 모두에게 공개입니다.

게임 관리

게임을 보이거나 숨겨요

🟢목록에 공개

홈에서 누구나 게임을 찾아 들어갈 수 있어요.

⚪목록에서 숨김

홈 목록에서만 사라져요. 전에 받은 링크는 열릴 수 있어요.

🟠서비스 점검

기존 링크를 열어도 “잠시 쉬는 중” 안내가 나와요.

게임 설명을 바꾸려면

  1. 게임 관리에서 게임 오른쪽의 수정을 눌러요.
  2. 제목, 한 줄 설명, 상태를 바꿔요.
  3. 사용자에게 보여줄 게임 방법에서 규칙과 1·2·3단계를 적어요.
  4. 수정 적용 → 임시 저장 → 미리보기 → 게시하기 순서로 눌러요.

디자인과 메뉴

한 번 바꾸면 전체에 적용돼요

☰ 메뉴 관리

이름과 연결 주소를 바꾸고, 화살표로 순서를 옮겨요. 표시 체크를 끄면 메뉴가 사라져요.

🎨 디자인

서비스 이름, 글꼴, 글자 크기와 색을 바꿔요. 오른쪽 휴대폰 화면에서 바로 확인할 수 있어요.

주소를 잘못 바꾸면 메뉴가 열리지 않을 수 있어요. 주소를 바꾼 뒤에는 꼭 미리보기에서 눌러 보세요.

광고 관리

광고는 두 스위치를 모두 켜요

  1. 전체 광고를 켜요.
  2. 사용할 광고 자리의 이 자리 사용도 켜요.
  3. 배너 이미지와 눌렀을 때 갈 주소를 넣어요.
  4. 광고를 보여주지 않을 게임 이름은 “광고 제외 게임”에 적어요.
처음에는 게임 결과 아래 한 자리만 사용하는 것이 가장 보기 편해요.

실수했을 때

게시 이력에서 되돌릴 수 있어요

게시 이력에는 예전에 게시한 설정이 차례로 남아요. 돌아가고 싶은 버전의 복원을 누르면 그 내용이 새 버전으로 다시 게시됩니다.

⚠ 복원은 게임 파일 자체를 되돌리지 않아요. 관리센터에서 바꾼 메뉴·설명·디자인·광고 설정을 되돌립니다.
