# 섯다 한판 · 첫 플레이 버전

- 경로: `/t/seotda/`. 메인 목록에는 아직 노출하지 않는 별도 체험 화면.
- 기존 크림·코랄 화면과 초록 테이블, 직접 그린 SVG 화투. 외부 이미지나 서비스 없이 플레이 가능.
- 컴퓨터와 3장 섯다: 서로 겹치지 않는 세 장을 받고 한 장을 버려 두 장으로 겨룬다. 버릴 패를 선택할 때 남는 족보를 확인하고 확정한다.
- 각자 100 가상 칩, 최대 5라운드. 0칩이면 조기 종료. 마지막 칩 수로 승패를 결정한다. 충전·환전·실물 보상 없음.
- 참가비 각 5칩. 사용자 체크/추가 10·20칩/올인/다이 → 컴퓨터 콜/레이즈/다이 → 레이즈 시 사용자 콜/다이. 상대의 보유 칩까지만 베팅 가능하며, 부족한 참가비도 작은 보유액에 맞춘다.
- 기본 족보: 38광땡 > 13·18광땡(동급) > 장땡~1땡 > 알리 > 독사 > 구삥 > 장삥 > 장사 > 세륙 > 9끗~0끗. 특수 역전·재경기 규칙은 적용하지 않고 게임방법에 명시한다.
- 컴퓨터는 자기 세 장에서 최강 조합을 남긴다. 베팅 판단 함수는 자기 두 장과 공개 베팅만 받으며 사용자 패를 참조하지 않는다. 약한 패의 블러핑도 포함한다.
- 새로고침/이탈 시 현재 경기 초기화. 서버 저장·실시간 대전·랭킹은 이 버전의 범위에 포함하지 않는다.

## 검증

- `node test/seotda.js`: 가능한 두 장 190조합, 세 장 1,140조합, 무작위 2,000경기, 기본 족보와 비김, 선택 확정, 칩 보존, 짧은 스택/올인, 중복 결제 방지, 컴퓨터 입력 독립성.
- `node scripts/check-seotda.cjs`: 실제 브라우저 320/390/768/1024px, 선택 변경/확정, 비공개 상대 패, 족보 모달/키보드 포커스, 콜/다이/레이즈/올인, 5라운드/재시작. 캡처는 무시되는 `output/seotda/`에 생성.
- 공용 페이지 smoke 및 asset 버전 검사에 포함. 규칙 검사는 `npm test`에도 등록.
