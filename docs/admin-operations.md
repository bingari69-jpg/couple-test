# 관리센터 운영 개선 · 2026-09-15

## 적용 내용

- 메뉴: 운영 현황 / 콘텐츠 관리 / 홈 꾸미기 / 문의함 / 광고·홍보 / 게시·설정.
- 편집 폼 입력이 즉시 초안에 반영된다. 기기에 자동 보관하고 1.8초 대기 후 서버 초안을 자동 저장한다. 미저장 / 저장된 미게시 초안 / 게시 완료를 구분한다.
- 게시 전 변경 목록 확인, 실제 페이지 미리보기, 초안 JSON 내려받기·로컬 복구, 최신 서버 설정 불러오기를 제공한다.
- 서버의 revision을 행 잠금 안에서 검사한다. 다른 탭·기기의 변경 이후 저장/게시/복원은 충돌로 거절한다. 구형 쓰기 RPC의 직접 실행 권한을 제거하여 우회 덮어쓰기를 막는다.
- 콘텐츠 숨김은 행 삭제 대신 visibility 변경이다. 알려진 앱 콘텐츠만 공개할 수 있다. 관리자 추천·지정 순서 또는 기존 인기 우선 순서를 선택한다.
- 편지지 표시/추천/순서, 글꼴·스티커 선택 목록을 관리한다. 숨긴 자산도 기존 편지·저장 초안 읽기에는 남긴다.
- 한국 날짜 기준 계절 안내 시작/종료, 제목/설명/버튼 편집. 기간 밖에는 기본 편지 안내를 사용한다. 변경은 게시 이후 적용된다.
- 문의함: 상태별 조회, 20개씩 페이지 이동, 개인정보 안전 출력, 상태 변경. 이메일은 발송하지 않는다. 문의 상태 변경은 초안 게시와 별개로 즉시 저장된다.
- 모바일에서도 콘텐츠 상태와 로그아웃을 사용할 수 있다.

## 통계 기준

`share_method`의 `v2:` 접두어로 개선된 클라이언트의 이벤트를 구분한다. 기존 RPC를 그대로 사용하여 SQL 배포 순서와 무관하게 수집이 가능하다. 이 접두어는 클라이언트 버전 표시이며 인증이나 완전한 봇 판별 장치가 아니다.

- noljago.co.kr/www.noljago.co.kr 외 도메인, admin_preview=1, webdriver, 관리자 세션 및 이 브라우저 제외 설정은 GA/자체 수집에서 제외한다.
- 관리자로 진입하면 브라우저 제외 설정을 켠다. 기존에 열린 페이지는 새로고침해야 GA에도 적용된다. 광고 이벤트의 별도 경로도 같은 제외 기준을 적용한다.
- 일반 버튼 클릭을 시작으로 추정하지 않고 링크 생성/응답을 게임 종료로 중복 변환하지 않는다. solo_started는 별도 유지한다.
- 명시 이벤트가 없는 콘텐츠는 시작/종료가 적게 집계될 수 있다. 모든 게임의 회차별 퍼널을 완성한 상태는 아니며 완료율 대신 이벤트 수로 표시한다.
- 공유는 시도 기록이다. 전송 성공, 개별 초대장 전환율, 실제 사람 수를 의미하지 않는다. GA 활성 사용자와 방문 브라우저는 직접 비교할 수 없다.
- 한국 날짜 경계, 사용자 지정 1~90일, 직전 동일 일수 비교, 날짜별 방문 브라우저, 정렬 제공. 오늘은 진행 중인 수치다.
- 이전/개선 후 기록을 선택하여 구분하며 과거 기록에서 개발자 접속을 임의로 삭제하지 않는다. 조회 오류 시 0으로 바꾸지 않고 마지막 성공 값과 오류를 표시한다.

## SQL 및 배포

`supabase/migrations/20260915_admin_operations.sql` 전체 적용 필요. 사용자가 이 세션에서 실행 완료를 확인했다. 운영 서버의 신규 조회 RPC가 존재하고 익명 호출을 거절하는 것도 확인했다. 실제 관리자 로그인 자격 증명을 사용한 운영 쓰기 테스트는 하지 않았다.

서버 미적용 시 새 UI는 기존 조회로 대체하고 로컬 초안 보관을 유지하지만, 안전하지 않은 구형 쓰기로 우회하지 않는다. SQL 적용 후 관리 화면을 새로고침한다.
