# 같이놀자 관리센터 연결 방법

관리센터 코드는 `/admin/`에 있으며, Supabase에 관리자용 테이블과 계정을 한 번 연결해야 사용할 수 있습니다.

화면에서 바로 보는 쉬운 설명서는 `/admin/guide/`에 있습니다. 관리센터에 로그인한 뒤 왼쪽 아래의 **관리자 사용법**을 눌러도 열립니다.

## 1. 관리자 SQL 실행

1. Supabase에서 `couple-test` 프로젝트를 엽니다.
2. 왼쪽 메뉴에서 **SQL Editor**를 엽니다.
3. **New query**를 누릅니다.
4. `supabase/migrations/20260911_admin_center.sql`의 내용을 전부 붙여넣습니다.
5. **Run**을 누릅니다.
6. 결과에 `admin_center_ready`가 표시되는지 확인합니다.

이 SQL은 관리자 명단, 초안, 공개 설정, 게시 이력, 익명 이용 통계와 이미지 저장소를 만듭니다. 공개 사용자는 게시된 설정만 읽을 수 있습니다.

## 2. 로그인 계정 만들기

1. Supabase 왼쪽 메뉴에서 **Authentication → Users**를 엽니다.
2. **Add user → Create new user**를 누릅니다.
3. 관리자 이메일과 비밀번호를 입력합니다.
4. 자동 이메일 확인 옵션이 보이면 확인된 사용자로 생성합니다.
5. 만들어진 사용자의 **User UID**를 복사합니다.

## 3. 계정에 관리자 권한 부여

SQL Editor에서 새 쿼리를 열어 아래 문장을 실행합니다. 따옴표 안에는 복사한 User UID를 넣습니다.

```sql
insert into public.app_admins (user_id, display_name, role)
values ('여기에-User-UID', '운영자', 'owner');
```

성공하면 한 행이 추가됩니다. 관리자 이메일과 비밀번호는 사이트 코드나 GitHub에 넣지 않습니다.

## 4. 관리센터 첫 게시

1. 로컬에서는 `http://127.0.0.1:4173/admin/`을 엽니다.
2. 배포 후에는 `https://bingari69-jpg.github.io/couple-test/admin/`을 엽니다.
3. 위에서 만든 계정으로 로그인합니다.
4. 현재 게임 목록과 디자인을 확인합니다.
5. **임시 저장**을 누릅니다.
6. **미리보기**로 홈 화면을 확인합니다.
7. **게시하기**를 누릅니다.

첫 게시 전에는 기존 로컬 설정이 그대로 사용됩니다. 게시 후부터 새로 방문하거나 새로고침한 화면에 관리 설정이 적용됩니다.

## 상태의 차이

- **목록에 공개:** 홈 목록에 나오며 기존 링크도 열립니다.
- **목록에서 숨김:** 홈 목록에서는 사라지지만 기존 카톡 링크는 계속 열립니다.
- **서비스 점검:** 기존 링크에도 점검 안내가 표시됩니다.

## 게임 사용법 바꾸기

1. **게임 관리**에서 바꿀 게임의 **수정**을 누릅니다.
2. **사용자에게 보여줄 게임 방법**에서 한 줄 규칙, 1·2·3단계, 도움말을 적습니다.
3. 동작을 직접 해보는 게임이면 짧은 연습 종류를 고릅니다.
4. **수정 적용 → 임시 저장 → 미리보기 → 게시하기** 순서로 누릅니다.

게시하면 각 게임의 **게임 방법** 버튼과 전체 `/guide/` 페이지에 같은 설명이 적용됩니다.

## 광고 등록

- 전체 광고를 켠 뒤 광고 자리도 각각 켜야 노출됩니다.
- 자체 배너는 HTTPS 이미지 주소와 이동 주소를 사용합니다.
- 관리센터에서 올린 이미지는 2MB 이하 PNG, JPG, WEBP, GIF만 허용됩니다.
- 게임별 `광고 사용 안 함` 설정이 전체 광고보다 우선합니다.
- AdSense는 승인된 `ca-pub-...` 값과 숫자형 광고 슬롯이 있어야 표시됩니다.

## 문제가 생겼을 때

- 로그인은 되지만 권한이 없다는 안내: `app_admins`에 올바른 User UID가 등록됐는지 확인합니다.
- 이미지 업로드 실패: `admin-assets` Storage bucket과 관련 정책이 생성됐는지 확인합니다.
- 설정이 사이트에 반영되지 않음: 임시 저장만 한 것은 아닌지, **게시하기**까지 눌렀는지 확인합니다.
- 잘못 게시함: **게시 이력**에서 정상 버전을 선택해 복원합니다.
