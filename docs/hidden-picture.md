# 숨은그림찾기

공개 경로: `/t/hidden-picture/`. 홈의 둘이놀기에는 `?mode=online`,
혼자놀기에는 `?solo=1`로 연결된다.

## 구성

| 방식 | 규칙 |
| --- | --- |
| 혼자 하기 | 1단계 숲속 소풍(2분) → 2단계 비 오는 서점(2분 30초) → 3단계 달빛 옥상 정원(3분). 한 단계의 물건 8개를 모두 찾으면 다음 단계가 열린다. |
| 친구와 하기 | 고른 같은 그림에서 30초 동안 찾은 개수로 대결한다. 도전장을 만든 사람이 끝낸 뒤 링크를 보내고, 친구가 끝내면 두 기록을 비교해 결과 링크를 보낸다. |

- 각 장면은 별·숟가락·왕관·물고기·열쇠·우산·하트·조개 8개를 담는다.
- 혼자 하기에서는 확대, 힌트 3회, 일시정지가 있다. 친구 대결에서는 공정한 30초를 위해 힌트와 일시정지를 숨긴다.
- 단계 해금은 이 기기의 브라우저에 저장한다. 게임 좌표와 도전 기록은 정적 페이지에 있으므로 부정행위 방지나 서버 순위 기능은 제공하지 않는다.
- 카카오 SDK가 아닌 브라우저의 공유 기능/링크 복사를 사용한다. 로컬 미리보기에서는 외부 공유를 막고 안내한다.

## 확인

`node scripts/hidden-picture-preview.cjs` → http://127.0.0.1:4196/t/hidden-picture/

`node scripts/check-hidden-picture.cjs`는 단계 해금, 실제 그림 좌표, 확대·힌트·일시정지,
30초 대결 UI와 도전장, 320/768/1100px, 이미지 실패 상태를 확인한다.

## 그림

내장 이미지 생성 도구로 만든 원본은 `t/hidden-picture/forest.png`,
`t/hidden-picture/bookshop.png`, `t/hidden-picture/rooftop.png`다.
사용자 첨부 이미지는 숨은 모양 찾기라는 형식의 참고였다. 새 장면과 새 그림은 독립적으로 만들었다.
프롬프트와 최종 그림에서 물건의 실제 위치가 달라질 수 있으므로 `game.js` 좌표는 완성 그림을 보고 측정했다.
