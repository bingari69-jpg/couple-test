# 편지 스튜디오 (2026-09-13)

## 작성 중 스티커·이모지 넣기 (후속 개선)

- 스티커와 이모지는 작성 화면 하단의 공통 도구에서 고른다. 도구를 열어도 편지 레이아웃이 아래로 밀리지 않으며, 모바일 키보드가 차지한 공간을 피하고 쓰던 커서가 도구에 가리지 않도록 이동한다. `계속 쓰기` 또는 Escape로 닫는다.
- 본문 편집기는 `contenteditable`이며 원래 textarea는 숨겨진 일반 텍스트 모델로 유지한다. 선택한 글을 이모지로 바꾸기, 같은 스티커 반복 삽입, 스티커 앞뒤 타이핑, 삭제/되돌리기/다시 실행, 한글 조합 중 입력 보존을 지원한다. 스티커는 글 사이에 최대 24개, 1개를 1자로 계산한다. 일반 글과 이모지를 합친 450자 제한은 유지한다.
- `assets/letter-inline.js`가 평문과 검증된 스티커 위치만 저장·복원한다. 본문의 `U+FFFC` 한 글자가 스티커 자리이며, `inl: [[UTF-16 위치, 허용된 스티커 ID], ...]`로 연결한다. HTML은 저장하거나 신뢰하지 않는다. 붙여넣기는 평문만 받으며 450자 초과 글도 보존한 뒤 전송을 막아 수정할 수 있게 한다. 본문 복사에서는 스티커를 `[고양이]` 같은 이름으로 바꾼다.
- 본문 스티커가 있는 링크는 v6, 없으면 v5. v6 링크의 `?v=6`은 구형 HTML 캐시로 새 링크를 열지 않게 한다. 기존 v1~v5 링크와 서명 아래 스티커 3개는 그대로 읽는다. 초안에는 `inline` 배열을 추가하며 저장 키/버전은 그대로다.
- 수신 화면과 Canvas 이미지 저장에도 같은 위치에 스티커를 넣는다. 이모지는 시스템 이모지 글꼴로 넘어가도록 본문 웹글꼴의 문자 범위를 분리했다. 이모지의 모양과 지원 범위는 기기의 시스템 글꼴에 따른다.
- `node scripts/check-letter-inline.cjs`: 터치 도구, 커서·선택 영역, 연속 스티커, 삭제·전체 떼기와 되돌리기, 한글 조합, 빈 줄, 안전한 붙여넣기, 한도 초과 보존, 초안 복원, v6 수신과 PNG 저장, 320~1100px 및 줄어든 화면 높이를 실제 Edge에서 검사한다. 외부 요청과 실제 메시지 전송은 하지 않는다. 화면은 `output/letter-inline/`.
- 최신 미리보기/배포는 HTML과 `letter-app.js`, `letter-inline.js`, `letter-export.js`, `letter-design.js`, `letter-studio.css`를 함께 반영해야 한다.

## 범위

- 사용자 제공 기존 화면에 맞춰 메뉴/버튼/제목/카드는 크림·코랄 계열과 주아 제목으로 통일. 수채화 6종이 앞에 오고 새 디자인 10종이 뒤에 추가됨. 편지 본문은 선택한 디자인과 글꼴을 그대로 사용.

- 최신 main `342a178`에서 `codex/letter-studio`로 분기. 게임·관리자·공용 UI는 그대로 유지. 공통 `kakao-share.js`에 편지 전용 카드 선택만 추가하고 모든 참조의 캐시 버전을 함께 갱신.
- 새 편지지 10종(심플·다이어리·캐릭터·로맨틱·축하 각 2종), 기존 수채화 6종 보존. 스타일 필터, 상황 선택, 찜, 바로 쓰기.
- 로컬 한글 글꼴 6종, SVG 스티커 24종(서명 아래 최대 3개), 봉인 스티커 6종, 이모지 30개, 글자색 5가지(추천 포함), 16~26px.
- 초안 자동 저장/복원/확인 후 삭제. 수신 링크를 읽는 동작은 작성 초안을 건드리지 않음. 저장 실패 시 글은 화면에 보존하고 안내.
- 450자 제한 유지. Intl.Segmenter로 눈에 보이는 글자 단위 계산(미지원 환경은 코드 포인트). 링크 길이 한도는 별도 확인.
- 본문 전체가 개봉 후 바로 보임. 긴 본문에 맞춰 입력칸 확장. 기억을 떠올리는 질문과 첫 문장 도움.
- 디자인별 카카오 공유 PNG 16종. 이름이나 편지 본문은 공유 카드 그림에 들어가지 않음.
- 직접 Canvas로 이미지 저장. 웹글꼴/일러스트 준비 후 생성, 긴 편지는 페이지로 나누고 장마다 다운로드. 파일 공유 지원 브라우저는 파일 공유 버튼도 제공.
- 짧은 답장은 문구가 입력된 작성 화면으로 연결되고 사용자가 보내야 전달됨. 카카오 인앱의 기존 외부 브라우저 답장 경로 보존.

## 파일과 링크

- `assets/letter-design.js`: 글꼴, 스티커 원본 벡터, 테마의 상하 장식, 글자 분할.
- `assets/letter-templates.js`: 16개 디자인. 기존 ID는 유지.
- `assets/letter-studio.css`: 편지 페이지에만 적용하는 스타일. 공용 social-ui.css는 수정하지 않음.
- `assets/letter-export.js`: 서버 업로드 없는 이미지 렌더링과 페이지 분할.
- `assets/letter-app.js`: 작성/초안/꾸미기/수신/공유.
- v1~v4 링크는 계속 읽음. 새 링크 v5에 `st`(스티커 ID 배열), `seal`, `color` 추가. 기존 본문/템플릿/서식 필드는 동일.
- localStorage: `gatchi_letter_draft_v1` (`{version:1,draft:...}`), `gatchi_letter_favorites_v1` (템플릿 ID 배열).
- 편지 초안은 계정이나 클라우드 동기화 기능이 아님. 사진·음성 업로드, 예약 전송, 클라우드 편지함, 긴 편지 모드는 이번 범위에 포함하지 않음.

## 재생성·검사

- `npm test`: 기존 전체 검사와 `test/letter-studio.js` 포함. 실제 메시지를 보내지 않음.
- `node scripts/check-letter-studio.cjs`: 임시 로컬 서버와 headless Edge에서 320~1100px, 실제 웹글꼴/Canvas, 16개 디자인 저장, 여러 장 저장, 초안 복원 확인. 외부 네트워크 차단. 미리보기는 gitignore의 `output/letter-studio/`.
- `node scripts/build-letter-cards.cjs`: 디자인별 카카오 이미지 재생성. 기존 공용 카드 빌드와 별도.
- 두 브라우저 스크립트는 번들 Playwright와 설치된 Edge 경로를 기본값으로 사용하며 `PLAYWRIGHT_PATH`, `BROWSER_PATH`로 변경 가능.
- `python scripts/build-letter-fonts.py`: Google Fonts의 OFL 글꼴 4종을 받아 WOFF2 변환. fontTools/brotli 필요. 기본체는 정적 400과 현대 한글 전체·자모·라틴·기호를 남겨 용량 축소. 라이선스는 각 글꼴 옆에 포함. 기존 Gaegu/Jua도 사용.

## 배포·기기 확인

새 이미지·글꼴·스크립트와 HTML을 함께 배포해야 함. 최초 편지 개선은 후속 사용자 요청으로 main에 반영해 배포했다. 로컬 미리보기에서 만든 공유 링크는 기존 정책에 따라 실서비스 주소로 만들어지므로, 새 규격을 배포하기 전에는 실제 전송에 사용하지 말 것.

모바일 크기 자동 검사는 실제 iPhone/Android의 카카오 인앱 동작을 대체하지 않음. 배포 후 새 카카오 카드 수신, 외부 브라우저 답장, iOS 사진 저장/파일 공유는 실제 기기에서 확인할 항목.
