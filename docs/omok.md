# 오목 한판

- 경로: `/t/omok/`. 기본 컴퓨터 대전, `?mode=online`은 카톡 초대 친구전, `?mode=local`은 같은 기기에서 둘이 두기. 홈 혼자놀기에서는 컴퓨터전, 둘이놀기에서는 친구전으로 연결한다.
- 15×15 자유오목. 흑 선공, 번갈아 한 알, 다섯 개 이상 연속이면 승리. 장목도 승리하며 삼삼·사사 금수는 없다. 225곳을 채우고 승자가 없으면 무승부.
- 작은 터치 영역의 오착을 줄이기 위해 자리 선택과 확정을 나눈다. 44px 방향 버튼과 키보드 방향키로 한 칸씩 이동할 수 있다. 마지막 돌 및 승리한 연결을 표시한다.
- 컴퓨터는 공개된 판만 사용한다. `가볍게`는 공격·방어 후보 평가, `생각하며`는 후보 8개에 대해 상대 응수 최대 6개를 살펴본다. 즉시 승리 및 상대 즉시 승리 차단이 우선이다. 전문 오목 엔진은 아니다.
- 컴퓨터전 무르기는 내 마지막 돌과 그 이후의 컴퓨터 돌을 함께 되돌린다. 백돌 플레이에서 컴퓨터의 첫 수만 있을 때는 무르지 않는다. 응수 대기 중 무르기·새 판·페이지 이탈 시 예약된 수를 취소한다.
- 컴퓨터전·같은 기기 대전은 페이지 메모리에만 있다. 온라인 친구전은 서버에 판을 저장한다. 같은 브라우저의 익명 접속 계정과 초대 링크로 재입장한다. 카톡 내 브라우저와 일반 브라우저는 저장 공간이 달라 같은 참가자로 인식되지 않을 수 있다. 별/레벨 진행도는 사용하지 않는다.
- `node test/omok.js`: 네 방향·가장자리·끊긴 줄·장목·무승부·착수 유효성·무르기·AI 승리/방어·실제 페이지 선택/확정/재시작.
- `node scripts/check-omok.cjs`: 실제 Edge에서 320/390/768/1024px, 터치·키보드·도움말 포커스·승리/재경기·흑/백 컴퓨터전·대기 중 무르기·양쪽 홈 진입 검사. 화면은 `output/omok/`에 저장한다.
- 기존 앱의 크림·코랄 색상과 로컬 주아 제목 글꼴, 공통 메뉴 아이콘을 사용한다. 로컬 체험 서버로도 검토할 수 있다.

## 카톡 초대 친구전

1. 친구와 → 이름 입력 → 초대방 만들기. 방장이 흑돌이다.
2. 카톡 초대 또는 링크 복사. 링크에는 무작위 128비트 방 코드만 포함하며 참가자의 인증 정보는 포함하지 않는다.
3. 친구가 링크를 열고 이름을 적어 입장하면 백돌이 된다. 세 번째 사람은 참가할 수 없다.
4. 서버가 차례·빈자리·판 버전을 확인한 뒤에만 돌이 화면에 놓인다. 상대의 새 수는 약 1.5초 간격으로 확인한다. 숨긴 탭에서는 확인을 멈추고 돌아오면 새로 읽는다.
5. 무르기는 없다. 양보하기는 확인 후 상대 승리로 끝난다. 두 사람 모두 한판 더를 눌러야 새 판이 시작된다. 방은 생성 후 24시간 유효하다.

### 운영 배포 상태

- SQL: `supabase/migrations/20260914_omok_rooms.sql`. 기존 테이블은 변경하지 않는 추가 마이그레이션이다. 2026-09-14 사용자가 운영 서버에 실행했고, 게임 커밋 `14abe3f`의 GitHub Pages 배포를 확인했다.
- 로컬 PostgreSQL(PGlite) 검사에 더해 운영 Supabase에서도 방 생성·입장·차례·동시 요청·저장·양보·재대결을 검증했다. 실제 서비스는 https://noljago.co.kr/t/omok/ 이다.
- 테이블은 RLS 활성화와 직접 접근 권한 회수로 보호한다. 인증된 참가자는 공개 RPC를 통해서만 변경한다. 모든 변경은 방 행 잠금과 버전/라운드 확인을 사용한다. 생성 재시도는 요청 UUID로 중복 방을 막는다. 방 생성은 사용자별 시간당 12회로 제한한다.
- 현재 로컬 주소에서는 카톡 공유를 막고 미리보기라는 안내를 표시한다. 실제 초대 링크는 배포된 `https://noljago.co.kr` 또는 `https://www.noljago.co.kr`에서만 만든다.
- 만료된 방은 RPC로 접근할 수 없지만 데이터베이스에서 자동 삭제하지는 않는다. 별도 보관 기간/정리 작업은 이후 운영 정책에 따라 정한다.

### 검증과 로컬 연결 체험

- `node test/omok-online-sql.cjs`: 실제 SQL 실행, 인증·직접 접근 권한·두 자리 제한·중복 생성/착수·잘못된 차례·네 방향 승리·장목·무승부·재대결 동의·양보·만료·생성 제한.
- `node scripts/check-omok-online.cjs`: 독립된 브라우저 2개와 실제 SQL로 초대·대전·새로고침·세 번째 참가 거절·연결 끊김/복구·응답 유실·재대결·모바일 배치를 확인한다. 외부 네트워크를 차단한 로컬 검사다.
- `node scripts/omok-preview.cjs`: `http://127.0.0.1:4186/t/omok/?mode=online&player=0`에서 로컬 DB 체험. 방을 만든 뒤 같은 방 해시를 붙인 `?mode=online&player=1#room=...` 주소를 별도 탭에서 열면 친구 역할을 체험한다. 로컬 전용이며 카톡으로 다른 휴대폰에 접속할 수 없다. 서버를 종료하면 체험 데이터는 사라진다. 이 스크립트는 운영 앱에 포함하거나 실행하지 않는다.
