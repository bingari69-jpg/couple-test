# 타임 점프 (`t/timejump/`)

병아리가 편지를 들고 다섯 시대(원시시대 → 고대 이집트 → 중세 → 산업시대 → 미래 우주)를 건너 우체통까지 가는 플랫포머.

## 파일
- `t/timejump/engine.js` — DOM 없는 판(스테이지 5개·물리). Node에서 `require`로 불러 검사한다.
- `t/timejump/index.html` — 시대 고르기·조작 버튼·캔버스 그리기·대결/혼자놀기 연결.
- `scripts/timejump-routes.cjs` — 빔 탐색으로 넘어짐 없는 클리어 경로를 찾아 `test/timejump-routes.json`에 저장.
- `scripts/timejump-preview.cjs` — 실제 페이지를 Edge로 열어 경로를 따라가며 `output/timejump/`에 장면 캡처.
- `test/timejump.js` — 경로 재생·물리 규칙·링크·혼자놀기·두 손가락 입력 검사.
- `assets/art/timejump.svg`(홈 카드), `assets/share-cards/timejump.png`(OG·카톡 카드, `build-share-cards.cjs`의 페이지 전용 항목).

## 동물과 점수
- 동물 13종: 뱀·검치호랑이·익룡(원시), 전갈·코브라·미라(이집트), 늑대·박쥐(중세), 쥐·태엽 로봇(산업), 우주 벌레·외계 괴물·해파리(우주). 크기와 점수는 `engine.js` 의 `SPECIES`.
- 움직임 세 가지: `walk` 땅 위 좌우, `fly` 공중에서 좌우+위아래, `hop` 좌우로 가며 튀어 오름. 모두 걸음 수만으로 위치가 정해진다(Math.sin 대신 삼각파).
- 위에서 밟으면 점수(작은 100 · 나는 150 · 큰 200)와 함께 튀어 오르고 공중 점프가 다시 채워진다. 옆에서 닿으면 넘어진다.
- **점수 = 밟기 점수 + 시간 보너스(제한 시간에서 남은 0.1초마다 1점)**. 우체통에 못 가면 시간 보너스는 0.
- 그림은 `index.html` 의 `CREATURES[종]`. 부딪힘 판정은 몸 크기 그대로 두고 그림만 1.2배로 그린다.

## 이야기
- 시대마다 시작 전 세 줄, 도착하면 한 줄(`index.html` 의 `STORY`). 처음 한 번만 자동으로 열리고(`gatchi_timejump_story_v1`), '📖 이 시대 이야기 보기'로 다시 연다. 건너뛰기 버튼은 바로 출발한다.

## 규칙
- 16ms 고정 걸음. 달리기 125px/s, 점프 높이 약 4.4칸·거리 약 4.6칸(한 칸 18px). 짧게 누르면 낮게 뛴다. 발판 끝 늦은 점프 96ms, 미리 누른 점프 128ms.
- 3단 점프: 공중에서 점프를 두 번 더 누를 수 있다(같은 힘). 땅에 닿거나 적을 밟으면 다시 채워진다. 화면 맨 위는 천장이라 3단이면 꼭대기에서 멈춘다.
- 적은 위에서 밟으면 사라지고 튀어 오른다. 옆에서 닿거나 가시·구멍이면 넘어짐 → 0.6초 뒤 마지막 깃발에서 다시(1초 무적), 시간은 계속 흐른다.
- 적·움직이는 발판 위치는 걸음 수만으로 정해져 두 사람이 같은 코스를 받는다(시드 없음).
- 둘이하기: 보내는 사람이 시대를 고르고 링크에 `g`(규칙 2판)·`t`(도착 시간)·`d`(넘어짐)·`l`(시대)을 싣는다. 기록 = 점수, 높을수록 승, 같으면 더 빨리 도착한 쪽. 5분이 지나면 시간 보너스 없이 밟기 점수만. `g` 가 없는 예전(시간 대결) 링크는 열지 않고 새 판으로 시작한다.
- 혼자놀기: `solo.js` 5단계. 제한 시간(90·120·150·180·210초) 안에 도착하면 클리어(`goal:0`, 표시는 `goalLabel`), ★★★은 '최단 시간 1.4배로 도착 + 동물 점수 절반'.

## 스테이지를 고칠 때
1. `engine.js`의 `LEVELS[n].build`를 고친다.
2. `node scripts/timejump-routes.cjs`(또는 `ONLY=3`)로 최단 경로와 사냥 경로(동물을 밟으며 가는 경로)를 다시 찾는다. 경로가 없으면 가장 멀리 간 칸을 알려준다.
3. `index.html`의 `LEVELS[].best`(★★★)를 '남은 시간 보너스(최단×1.4) + 동물 점수 절반'으로 다시 계산한다. `test/timejump.js`가 공식과 사냥 경로 달성 가능 여부를 검사한다.
4. `ROUTE=hunt node scripts/timejump-preview.cjs`로 동물이 나오는 화면을 확인한다.

## 운영
- 운영 SQL 없이 동작한다. 홈 목록은 로컬 목록을 서버 게시본 끝에 붙이고, 통계 이벤트는 게임 이름 제한이 없다.
- 완료 알림(`result-notify.js`)은 넣지 않았다. 넣으려면 `game_catalog`·완료 알림 허용 목록 SQL이 함께 필요하다.
- 관리센터에서 초안 저장→게시를 한 번 하면 게시본 게임 목록에도 들어간다.
