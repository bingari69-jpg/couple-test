같이놀자 개인정보 안내

2026년 9월 12일 기준

같이놀자는 카카오톡으로 편지·게임·심리 콘텐츠를 주고받는 무료 웹사이트입니다. 회원가입이 없고, 이름을 묻는 곳도 모두 선택 사항입니다. 아래는 이 서비스가 무엇을 저장하고 무엇을 저장하지 않는지에 대한 설명입니다.

서버에 저장하지 않는 것

  • 편지 본문은 서버에 보관하지 않습니다. 편지지·글꼴·내용은 카톡 링크 안에 담겨 받는 사람에게 바로 전달됩니다.
  • 게임·테스트의 답도 기본적으로 링크 안에만 담깁니다. 링크를 지우면 기록도 사라집니다.
  • 전화번호, 이메일, 생년월일, 위치 정보는 묻지 않으며 수집하지 않습니다.

서버에 잠시 저장되는 것

완료 알림 (기록 게임·심리 테스트)

친구가 게임을 끝내면 보낸 사람에게 "완료" 알림을 띄우기 위해, 친구가 마지막에 보던 결과 화면의 주소를 최대 7일간 저장합니다. 이 주소에는 두 사람이 고른 답과 입력한 이름이 포함됩니다. 이 정보는 링크를 만든 사람만 읽을 수 있고, 7일이 지나면 자동으로 삭제됩니다. 편지·운세·사다리·조편성·시험지에는 이 기능이 없습니다.

단체방

단체방 커피 내기를 쓸 때는 방 코드, 참가자 닉네임, 준비·제출 상태를 방이 끝날 때까지 저장합니다.

임시 익명 계정

완료 알림과 단체방을 위해 브라우저마다 임시 익명 번호가 하나 만들어집니다. 이름이나 연락처와 연결되지 않으며, 브라우저 데이터를 지우면 없어집니다.

브라우저 알림 구독

"화면을 닫아도 알림 받기"를 직접 누른 경우에만 브라우저의 알림 주소를 저장합니다. 알림 설정에서 끄면 더 이상 보내지 않습니다.

이용 통계

서비스를 개선하기 위해 어떤 게임을 몇 번 시작하고 완료했는지 같은 숫자를 Google 애널리틱스와 자체 저장소에 기록합니다. 이 통계에는 이름, 답변, 편지 내용, 내기 내용, 링크 주소가 들어가지 않습니다.

카카오톡 공유

"카톡으로 보내기"를 누르면 카카오 공유 기능이 열립니다. 누구에게 보낼지는 카카오톡 앱 안에서 정하며, 같이놀자는 받는 사람이 누구인지 알 수 없습니다.

광고

현재 외부 광고를 게재하지 않습니다. 앞으로 광고를 넣게 되면 이 페이지에서 먼저 안내합니다.

내 브라우저에만 남는 것

다시 입력하지 않도록 이름, 오늘 뽑은 운세 카드, 진행 중인 게임 상태를 사용자의 브라우저에만 저장합니다. 브라우저의 사이트 데이터를 지우면 함께 삭제됩니다.

문의와 삭제 요청

저장된 정보의 삭제를 원하거나 궁금한 점이 있으면 GitHub 저장소에 남겨 주세요. 완료 알림 기록은 요청이 없어도 7일 뒤 자동 삭제됩니다.
