# 마음 부적 앱 구조 초안

이번 단계에서는 홈과 배포본에 연결하지 않고, 화면 구조와 원화만 준비한다.

## 보내는 사람

1. 마음 고르기: 위로·곁·응원 부적 중 하나를 선택한다.
2. 이름 새기기: 받는 사람 이름과 기본 덕담 한 개를 고른다. 직접 한 줄도 허용한다.
3. 미리보기: 이름이 얹힌 부적과 덕담을 확인한다.
4. 보내기: 공통 카카오 미리보기 카드와 개인화된 링크를 전송한다.

## 받는 사람

1. 한지 봉투가 열리는 짧은 연출을 본다.
2. 이름이 새겨진 부적을 확인한다.
3. 부적의 의미와 보낸 사람의 덕담을 읽는다.
4. 이미지로 간직하거나 상대에게 새 부적을 답장한다.

## 구현 경계

- 개인 이름과 덕담은 서버에 저장하지 않고 URL 해시에 담는다.
- 카카오톡 공유 미리보기는 공통 이미지로 제공한다. 개인 이름은 링크를 연 뒤에만 표시한다.
- 저장 이미지는 같은 출처의 로컬 이미지와 로컬 폰트만 사용해 브라우저에서 합성한다.
- 실제 효험을 단정하지 않고 ‘마음을 전하는 작은 응원’이라고 안내한다.
- 이번 초안에는 동작 스크립트, 홈 연결, 카카오 공유, 분석 이벤트, 배포를 포함하지 않는다.
