# 마음 전하기 카테고리 시안

## 메뉴 위치

- 기존 하단 메뉴의 `편지`를 `마음`으로 변경한다.
- 기존 홈 상단의 `마음 전하기` 명칭은 유지한다.
- `마음`을 누르면 이 진열대 화면으로 이동한다.
- `놀이`와 `심리테스트`는 현재 분류를 그대로 유지한다.

## 진열 상품

1. 마음 부적: 위로와 응원. 이름을 새기고 의미와 덕담을 보낸다.
2. 상장·임명장: 칭찬과 고마움. 이름, 상 이름, 수여 이유를 적는다.
3. 마음 쿠폰: 약속과 만남. 쿠폰 내용과 유효기간을 정해 보낸다.

기존 편지는 없애지 않고 진열대 아래의 `편지 한 장 천천히 쓰기`로 연결한다. 새 콘텐츠 범위는 부적·상장·쿠폰 세 종류만 유지한다.

## 공통 제작 흐름

`종류 선택 → 디자인 선택 → 이름 각인 → 문구 선택/직접 입력 → 미리보기 → 카카오톡 보내기`

받는 화면은 `개봉 → 개인화된 물건 → 뜻/메시지 → 이미지로 간직하기 → 답장`의 공통 틀을 사용한다.

## 이번 시안의 범위

- 카테고리 화면과 상장·쿠폰 원화만 추가했다.
- 기존 홈·하단 메뉴는 아직 변경하지 않았다.
- 상장·쿠폰 제작 화면, 상태 저장, 공유, 테스트, 배포는 연결하지 않았다.
